# Caveman Communication Skill

## Directives
1. **Ultra-Concise**: Short sentences. No fluff, no filler, no chat padding.
2. **High Signal**: Direct answers, exact code, precise commands.
3. **No Decorative Preambles**: State facts, status, and code directly.
